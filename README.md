# Naomi Moonga — Student Portfolio

A responsive student portfolio website created with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for desktop and mobile screens
- Light/dark theme switch
- Project cards with category filters
- Click-to-enlarge photo gallery using an HTML dialog
- Contact form validation with accessible feedback
- Existing photo, audio, and video assets from Activity 2

## Run locally
Open `index.html` in a modern browser. No build tools or external libraries are required.

## Deploy on Render
1. Push the contents of this folder to a GitHub repository.
2. In Render, create a **Static Site** and connect the repository.
3. Set the publish directory to `.` (the folder containing `index.html`).
4. No build command is needed for this plain HTML/CSS/JavaScript site.
5. Deploy and test the published URL on desktop and mobile.

## Notes
The contact form validates input in the browser only. It does not send or store messages because no backend service is configured. Replace the sample project descriptions with accurate details of completed work before submission.
